# C14-Online-Voting-System  
  
A simple and responsive user interface for an Online Voting System developed using **HTML, CSS, and JavaScript** as part of a DBMS project.  
  
## Pages  
- Home  
- Login  
- Registration  
- Dashboard  
- Voting  
- Results
- Profile
- Admin  
  
## Technologies Used  
- HTML5  
- CSS3  
- JavaScript  
  
This UI demonstrates the basic workflow of an Online Voting System with a clean and user-friendly design.
